# I am Luan De La Vega



## Backend Developer | Java | Spring | Microservices | RESTful APIs | AWS | DevOps


------
Desenvolvedor Back-end com 4 anos de experiência em Java. Possui vasta experiência em frameworks Spring, como Spring Boot, Spring MVC, Spring Data e Spring Security.
